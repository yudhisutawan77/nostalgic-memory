my grandmother's rice pot fogging my glasses while she pretended not to
notice I'd stolen the crispy bottom.

## Entry

> Every August my grandmother lifted the lid off the rice pot with a folded dish towel, and the steam fogged my glasses while she pretended not to notice I had already stolen the crispy bottom.

## How it works

`main.py` writes that single sentence to the entry file the sealed scorer
reads (`$ENTRY_OUT` as a file, else `$ENTRY_OUT_DIR/entry.txt`, else
`/output/entry.txt`), validating the 1–280 character gate first. No network,
no secrets, no dependencies — plain Python 3.
